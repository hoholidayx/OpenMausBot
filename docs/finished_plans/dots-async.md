# Dots 异步收发

Dots 私聊每次发送都在本机持久受理，随后由收件箱处理回执。输入框可连续发送，聊天只展示用户消息和实际来信。编辑后的消息使用自己的请求 ID，旧请求的答复留在原分支。

工作搭档落盘后进入等待外部回执状态。真实终态按子任务 ID 结算，沿用原消息署名交付。重启接续已受理的发件、旧版排队消息和已到达的回执。明确停止只作用于选定请求。
